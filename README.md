# Dimensions

An interactive web app that teaches spatial dimensions experientially. See `PLAN.md` for the design rationale and task-by-task build guide, and `PROGRESS.md` for current status.

## Commands

- `npm run dev` — local dev server
- `npm test` — Vitest
- `npx playwright test` — browser/e2e tests
- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run format` — Prettier (write)
